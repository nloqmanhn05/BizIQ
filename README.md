## 💡 The Inspiration (The Problem)
Small to medium business owners often struggle to make sense of their raw sales data. Spreadsheet fatigue is real, and hiring a dedicated data analyst is expensive. Most existing BI tools are either too complex for non-technical users or lack the interactive depth to answer "What If" questions.

## 🎯 Our Solution
**BizIQ** bridges the gap between raw data and strategic action. By combining an intuitive dashboard with a powerful AI business consultant, we provide:
1. **Instant Clarity**: Turn messy spreadsheets into beautiful, interactive visualizations.
2. **Contextual Conversations**: Chat with your data using an AI that understands your specific business metrics.
3. **Future Foresight**: Simulate business decisions before you commit resources.

## ✨ Core Features

| Feature | Description |
| :--- | :--- |
| **📊 Advanced Dashboard** | High-fidelity charts (Revenue, Gross Margin, YoY Growth) for a 360° view of business health. |
| **🤖 AI Business Assistant** | A streaming chat interface powered by Gemini/OpenAI that acts as your 24/7 business consultant. |
| **📈 Financial Simulator** | Interactive "What If" engine to predict how pricing or COGS changes impact profitability. |
| **💡 Smart Decisions** | Automated anomaly detection and strategic recommendations generated directly from your data. |
| **📁 Data Ingestion** | Seamless drag-and-drop support for Excel (`.xlsx`) and CSV files. |
| **🎨 Premium UI** | A sleek "Modern Dark" aesthetic built with Framer Motion for buttery-smooth transitions. |

## 🛠️ Technology Stack

- **Frontend**: `React 19`, `Vite`, `Tailwind CSS`, `Framer Motion`, `Lucide React`, `Recharts`
- **Backend**: `Node.js`, `Express`, `Multer`
- **AI Engine**: `OpenAI SDK` (Gemini API Compatible), `Server-Sent Events (SSE)`
- **Data Parsing**: `XLSX`, `PapaParse`

## 🚀 Getting Started

### 1️⃣ Clone & Navigate
```bash
git clone https://github.com/nloqmanhn05/BizIQ.git
cd BizIQ
```

### 2️⃣ Automatic Installation
```bash
npm install
npm run install-all
```

### 3️⃣ Set Up Environment
Create a `.env` file in the `biziq` directory:
```env
GEMINI_API_KEY="your_gemini_api_key_here"
AI_API_KEY="your_openai_api_key_here"
AI_MODEL="gemini-1.5-flash"
PORT=3000
```

### 4️⃣ Launch the Engine
```bash
npm run dev
```
Open [**http://localhost:3000**](http://localhost:3000) to see the magic.
