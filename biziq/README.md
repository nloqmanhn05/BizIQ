# BizIQ - AI Business Intelligence App

This is the main application folder for BizIQ.

## 🚀 Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment**:
   Create a `.env` file with your `GEMINI_API_KEY`.

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

## 🛠 Features

- **Chat**: Interactive AI business assistant.
- **Dashboard**: KPI visualization and financial trends.
- **Simulator**: Scenario-based financial modeling.
- **Upload**: Data ingestion for Excel/CSV files.

## 📁 Folder Structure

- `src/`: Frontend React application.
- `server.ts`: Express backend with AI streaming support.
- `uploads/`: Local directory for uploaded business data.
- `vite.config.ts`: Vite build configuration.
